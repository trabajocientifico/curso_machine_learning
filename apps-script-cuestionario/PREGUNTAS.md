# Banco de preguntas para revisión docente

10 preguntas conceptuales. Selección única. Cada respuesta correcta vale 5 puntos; incorrecta, 0.

## 1. ¿Cuáles son los dos tipos de aprendizaje que se trabajaron principalmente en el módulo?

A. Lineal y digital.

B. Supervisado y no supervisado.

C. Rápido y lento.

D. Manual y automático.

**Correcta: B.** En el módulo se estudian el aprendizaje supervisado, con respuestas conocidas, y el no supervisado, que busca estructura sin esas respuestas.

Fuente: [index/2-1-clase-fundamentos.html](../index/2-1-clase-fundamentos.html).

## 2. ¿Cuál es la principal diferencia entre un sistema basado en reglas y uno de machine learning?

A. El sistema de reglas siempre necesita más datos.

B. Machine learning funciona sin datos.

C. Los dos requieren escribir a mano todas las reglas de decisión.

D. En el primero se escriben las reglas; en machine learning el modelo aprende patrones a partir de datos.

**Correcta: D.** En un sistema basado en reglas una persona define cómo decidir. En machine learning se ajusta un modelo a partir de ejemplos.

Fuente: [index/2-1-clase-fundamentos.html](../index/2-1-clase-fundamentos.html).

## 3. ¿Qué caracteriza a los datos usados para entrenar un modelo de aprendizaje supervisado?

A. Incluyen ejemplos con la respuesta que se quiere aprender a predecir.

B. No pueden contener números.

C. Siempre están organizados en grupos sin etiquetas.

D. Solo pueden ser imágenes.

**Correcta: A.** Los ejemplos de entrenamiento incluyen una respuesta conocida: por ejemplo, el precio de una vivienda o si un estudiante continuó sus estudios.

Fuente: [index/2-1-clase-fundamentos.html](../index/2-1-clase-fundamentos.html).

## 4. ¿Cuál de estas técnicas NO corresponde al aprendizaje supervisado, tal como se presentó en clase?

A. Regresión lineal.

B. Regresión logística.

C. K-means para formar grupos.

D. Árbol de decisión para predecir una categoría.

**Correcta: C.** K-means forma grupos por semejanza sin necesitar una respuesta o etiqueta previamente asignada a cada caso.

Fuente: [index/2-1-clase-mapa-tecnicas.html](../index/2-1-clase-mapa-tecnicas.html).

## 5. ¿Cuál de estas situaciones es un ejemplo de aprendizaje no supervisado?

A. Predecir el precio de una vivienda usando ejemplos con precios conocidos.

B. Agrupar municipios por sus características, sin asignarles grupos de antemano.

C. Reconocer correos no deseados a partir de correos ya etiquetados.

D. Predecir si un estudiante desertará usando casos con resultados conocidos.

**Correcta: B.** Buscar grupos de municipios parecidos sin etiquetas previas es una tarea de agrupamiento no supervisado.

Fuente: [index/2-3-clase-no-supervisado.html](../index/2-3-clase-no-supervisado.html).

## 6. Si se quiere predecir si un correo es «no deseado» o «normal», ¿qué tarea se está realizando?

A. Clasificación, porque se predice una categoría.

B. Regresión, porque se predice un valor numérico continuo.

C. Agrupamiento, porque no existen categorías conocidas.

D. Reducción de dimensiones, porque se eliminan correos.

**Correcta: A.** La clasificación predice categorías. En este ejemplo las categorías son «no deseado» y «normal».

Fuente: [index/2-1-clase-mapa-tecnicas.html](../index/2-1-clase-mapa-tecnicas.html).

## 7. Si se quiere estimar el precio de una vivienda a partir de sus características, ¿qué tarea corresponde?

A. Clasificación de imágenes.

B. Agrupamiento sin etiquetas.

C. Detección de correos no deseados.

D. Regresión, porque se quiere predecir un valor numérico.

**Correcta: D.** La regresión se utiliza para predecir cantidades, como un precio, un ingreso o una temperatura.

Fuente: [index/2-2-clase-regresion-lineal.html](../index/2-2-clase-regresion-lineal.html).

## 8. ¿Para qué se reservan datos de prueba que el modelo no utilizó durante el entrenamiento?

A. Para que el modelo memorice también esos datos antes de evaluarlo.

B. Para evitar revisar la calidad de los datos.

C. Para evaluar cómo funciona el modelo en casos que no ha visto.

D. Para garantizar que nunca cometerá errores.

**Correcta: C.** Los datos de prueba permiten evaluar si lo aprendido resulta útil en casos nuevos. Un buen resultado no garantiza que el modelo nunca se equivoque.

Fuente: [index/2-1-clase-fundamentos.html](../index/2-1-clase-fundamentos.html).

## 9. Un modelo funciona muy bien con los datos de entrenamiento, pero falla en casos nuevos. ¿Qué podría estar ocurriendo?

A. Sobreajuste: se adaptó demasiado a los ejemplos de entrenamiento.

B. El modelo ya aprendió todo y no necesita evaluación.

C. Los datos nuevos siempre están equivocados.

D. El modelo dejó de ser machine learning.

**Correcta: A.** El sobreajuste ocurre cuando el modelo se adapta demasiado a particularidades del entrenamiento y generaliza mal a nuevos casos.

Fuente: [index/2-2-clase-arbol-decision.html](../index/2-2-clase-arbol-decision.html).

## 10. Después de obtener los resultados de un modelo, ¿qué es lo más adecuado en una investigación?

A. Aceptar todas las predicciones como verdades definitivas.

B. Comunicar solo los resultados que parecen favorables.

C. Suponer que una predicción demuestra automáticamente una causa.

D. Interpretarlos en el contexto del problema y comunicar sus alcances y limitaciones.

**Correcta: D.** Los resultados requieren interpretación y evaluación en contexto. Una predicción por sí sola no demuestra causalidad ni elimina la incertidumbre.

Fuente: [index/2-1-clase-fundamentos.html](../index/2-1-clase-fundamentos.html).
